# Forms: a request, a delivery note, a morning report, "what's next"

Short, plain, the same every time, so nobody has to guess what is missing.

## An art request (GD → AD)

```
Request: <what, in one line>  (chapter N, wave M)
For: <where in the game it shows; the screen, the size on screen at the judging size>
Exists now: <the stand-in or the earlier piece, with its path>
Budget: <pixels, frames, file size, atlas form>  (docs\art-demands.md)
Decided: <Robin's words with dates that bind it>
Yours to choose: <what the AD decides>
Reference: <what Robin likes, if anything>
Needed: <when; what waits on it>
Big work? <yes: three concepts first / no>
```

## A sound request (GD → SD)

```
Request: <what, in one line>  (chapter N, wave M)
Plays when: <the moment in the game; how often; over what music>
Exists now: <the stand-in, the library sound tried>
Budget: <format, length, loop, size>  (docs\sound-demands.md)
Decided / yours to choose / reference / needed: as above
A song? <yes: three one-minute versions / no>
```

## A delivery note (`out\<name>\NOTES.md`)

```
# <name>  (<Studio tag>, <date>)
What it is: <one or two lines>
What changed and why: <in Robin's words where they are his, with dates; "mine" for the studio's choices>
The numbers: <sizes, frames and delays, loop points, gains, peak and loudness, memory>
How the game uses it: <the drop-in: copy the whole folder to ...; the data file; the key names>
Open: <what is still undecided; what Robin should look at>
Not tested: <honest list>
Origin and licence: <for anything taken from outside, with the path or link>
Where to see or hear it: <the chat file; the page's tab and row>
```

## A morning report (GD, after a long session alone)

```
Done (each committed): <item: what, the test that covers it, the commit>
Asked of the studios: <request, who, what came back>
Checked: <tests, typecheck, the pane at the judging size; the frame log on the phone if run>
Waits for Robin: <decisions, felt numbers, picks between concepts or songs>
Found: <bugs, mistakes, ideas, each where it was written (idea bank, lessons)>
Next, if nothing changes: <the next three items>
```

## "What's next" (GD, any time Robin asks)

Three to five items from `docs\plan-chapter-N.md`, in order, each with who does it and what it waits on; then one line
on where the chapter stands (items built, items checked by Robin, items open). Nothing else.
